SOUL PLATFORM 0.6.1 — INSTALACION EN WINDOWS
==============================================

Requisitos:
- Windows 10 22H2 o Windows 11.
- Conexion a Internet solo si faltan Python, Ollama o los modelos locales.
- Aproximadamente 3 GB libres para Python, Ollama, BGE-M3 y el cerebro minimo.

Pasos:
1. Extrae TODO el contenido del ZIP en una carpeta normal.
2. Haz doble clic en Instalar-SOUL-Windows.bat.
3. Espera el mensaje: "Instalacion terminada correctamente".
4. Busca el icono violeta SOUL junto al reloj de Windows.

El instalador:
- verifica el SHA-256 del paquete incluido;
- detecta Python 3.13 x64, Ollama, BGE-M3 y un cerebro local;
- instala con WinGet solo lo que falta y omite lo que ya esta sano;
- instala las dependencias Python desde la wheelhouse cerrada del ZIP, sin PyPI;
- verifica WHEELHOUSE.sha256 y usa pip --no-index;
- usa gemma3:1b como cerebro minimo solo si no encuentra ningun modelo generativo;
- crea un entorno aislado en %LOCALAPPDATA%\SOUL\venv;
- no pide administrador ni modifica el Python del sistema;
- conserva identidad y memorias al actualizar o reinstalar;
- escucha solamente en 127.0.0.1:11435 y exige token.
- instala SOUL Tray al iniciar sesion como el usuario normal, nunca SYSTEM.

Para diagnosticar sin cambiar nada:

  Instalar-SOUL-Windows.bat -Check

Para impedir que instale prerrequisitos del sistema:

  Instalar-SOUL-Windows.bat -NoBootstrap

Compatibilidad demostrada: Windows 10 22H2/11, Codex CLI/Desktop, Claude Code,
Ollama y clientes OpenAI-compatible. Otras apps requieren un hook/API oficial;
SOUL las registra cuando exponen una superficie compatible, no las parchea.

No compartas %LOCALAPPDATA%\SOUL\proxy.token.
La interfaz solo lo copia cuando pulsas explicitamente "Copiar token local".
